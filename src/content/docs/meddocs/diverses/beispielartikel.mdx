## Textformatierung

Normaler Fließtext steht neben **fett hervorgehobenem Text**, *kursivem Text*
und ***fett-kursivem Text***. Ein ~~gestrichener Ausdruck~~ und
`Inline-Code` ergänzen den Vergleich. Lorem ipsum dolor sit amet, consectetur
adipiscing elit.

Ein [interner Link zur Diverses-Übersicht](/meddocs/diverses/) und ein
[externer Link zum MedNerds-Repository](https://github.com/NodalDev/MedNerds)
zeigen die Linkdarstellung innerhalb eines Absatzes.

Dieser Satz beginnt in einer Quelltextzeile.
Die nächste Quelltextzeile bleibt Teil desselben Absatzes: ein weicher Umbruch.

Diese Demo-Zeile endet mit einem bewussten harten Umbruch.<br />
Diese zweite Zeile gehört weiterhin zum selben Absatz.

### Weitere native Textauszeichnungen

Die Taste <kbd>Enter</kbd>, ein <mark>markierter Begriff</mark>,
ein Index wie Demo<sub>2</sub> und eine hochgestellte Ziffer wie Demo<sup>3</sup>
zeigen zusätzliche HTML-Auszeichnungen. Die Abkürzung
<abbr title="Markdown mit Komponenten">MDX</abbr> besitzt eine ausgeschriebene Erklärung.

## Codeblöcke

### Einfacher Codeblock

```ts
const example = 'MedNerds';
console.log(example);
```

### Codeblock mit Titel

```ts title="beispiel.ts"
const page = {
  title: 'Beispielartikel',
  mode: 'demo',
};

console.log(page.title);
```

### Zeilenhervorhebung

Die zweite und vierte Zeile sind hervorgehoben.

```ts title="hervorhebung.ts" {2,4}
const title = 'Beispielartikel';
const mode = 'showcase';
const sectionCount = 3;
console.log({ title, mode, sectionCount });
```

### Hervorgehobener Ausdruck

```ts title="ausdruck.ts" "MedNerds"
const project = 'MedNerds';
const message = `Willkommen bei ${project}`;
console.log(message);
```

### Diff mit hinzugefügter und entfernter Zeile

```diff title="textänderung.diff"
- const heading = 'Alter Demo-Titel';
+ const heading = 'Neuer Demo-Titel';
  console.log(heading);
```

### Terminal-Beispiel

```sh title="Terminal"
npx astro check
npm run build
```
